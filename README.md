## Instalasi

### Windows
1. Unduh file installer `.exe`.
2. Jalankan installer, ikuti langkah berikutnya.
3. Buka aplikasi BazzJD dari Start Menu.

### Android
1. Unduh file `.apk`.
2. Aktifkan izin **Install from unknown sources** bila diperlukan.
3. Tap APK → instal → buka aplikasi.
